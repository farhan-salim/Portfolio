- **🛠️ Confirmed Skills Grid**: Visual cards highlighting core technologies with official SVG logos and descriptions.
- **📂 Live GitHub API Integration**: Real-time integration with the GitHub REST API to fetch and display recent public repositories with instant fallback support.
- **📜 Certificates & Credentials System**: Expandable credentials section with category filtering and an accessible interactive modal viewer for image and PDF certificates.
- **🗺️ Journey Timeline**: Visual progress tracking from S5 IT coursework to current development milestones and future internship goals.
- **📱 Fully Responsive Design**: Optimized layout across mobile, tablet, and desktop screens with a mobile drawer menu.
- **⚡ Zero Framework Bloat**: Pure Vanilla HTML5, CSS3, and modern JavaScript for blazing-fast load times.

## 🚀 Running Locally

You can preview and run this portfolio locally on your machine using any of the methods below:

### Option 1: Using Vite (Recommended)

```powershell
# Navigate to project directory
cd "path/to/Portfolio"

# Start Vite dev server directly (no install needed)
npx -y vite --port 5173
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

---

### Option 2: Using Python Built-in HTTP Server

```powershell
python -m http.server 8000
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.

---

### Option 3: Using VS Code Live Server Extension
1. Open the project folder in **Visual Studio Code**.
2. Right-click [`index.html`](index.html) and select **"Open with Live Server"**.

---

## 🌐 Deploying to GitHub Pages

To host this portfolio live for free using GitHub Pages:

1. Push this repository to GitHub: `https://github.com/farhan-salim/Portfolio`
2. In the repository on GitHub, go to **Settings** → **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Set the branch to `main` (or `master`) and folder to `/ (root)`, then click **Save**.
5. Your live portfolio will be published at `https://farhan-salim.github.io/Portfolio/`.
